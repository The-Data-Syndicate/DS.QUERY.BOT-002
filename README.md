DS.QUERY.BOT-002 transforms a simple AI chatbot into a structured desktop application focused on controlled interaction, usability, and persistence.

* Stable AI communication via API key
* Organized user interaction layers
* Persistent conversational memory

* Lightweight deployment experience

# 🧠 DS.QUERY.BOT-002

**DS.QUERY.BOT-002** is the evolved form of its predecessor — no longer just a chatbot, but a controlled AI interaction system designed for structured usage and stability.

Built on the foundation of **DS.QUERY.BOT-001**, this version introduces a refined desktop interface, persistent memory through chat history, and safer interaction handling for a smoother AI experience.

---

## ✨ Features

* 🖥️ GUI-based interface using Tkinter
* 💾 Persistent chat history system
* 🔑 API key configuration through UI
* ⚠️ Improved error handling and stability
* 📚 Multi-view interface (Home, History, User Guide)
* 🔒 Controlled session handling with safe exit commands
* 📦 Portable desktop application with minimal setup
