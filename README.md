"DS.QUERY.BOT-002 is the evolved form of its predecessor — no longer just a tool, but a controlled system."
Built upon the foundation of DS.QUERY.BOT-001, this version introduces a refined interface, persistent memory through chat history, and structured interaction layers. The user now interacts through a guided environment, with improved stability and controlled API handling.

Key Improvements:
GUI-based interaction using Tkinter
Persistent chat history system
API key configuration via UI
Improved error handling (invalid key, rate limits, connection issues)
Multi-view interface (Home, History, User Guide)
Session control with safe exit commands

This version is designed as a portable desktop application, requiring minimal setup while providing a structured AI interaction experience.

"What was once a simple chatbot has now become a contained AI artifact — designed to be used, not tampered with."
